# 005 說明影片字幕與選項設定檔

取證日期：2026-10-29。輸入：`CSPPRG.EXE`（SHA-256 見 `workplace/disc/manifest.json`）；第一章記憶體傾印由 FerroGolem 探針取得（`~/cht/ferrogolem/workplace/runs/kgb-ch1dump`，cycles 1000、1,000,000,000 步）；反組譯 `objdump -m i8086`，位址為 load segment（188Bh）內偏移，資料段 2144h。

## 選項設定檔 CSP.CFG

- `16b8` 以 `2394` 把 `CSP.CFG` 的 6 個位元組讀進 `2144:0618`–`061D`（CX＝61Eh－618h）。已證實（程式碼）。
- `[061d]` 是字幕旗標：說明影片開啟前（`062b`–`0637`）若 `3271` 回 ZF 或 `[061d]` 非 0，就在影片旗標 DL 加上 4（有字幕）。開機時（`171a`–`1726`）沒有音效或語言索引 `[042e]`＜3 會強制設為 FFh。強推論。
- `[061c]` 是游標速度（`66a4` 交給 `int 33h` 000Fh）。強推論。
- 原版 `CSP.CFG` 為 `01 00 00 00 02 00`，字幕關閉。`tools/rust.sh` 新建暫存層時把第 5 位元組設為 FFh，讓說明影片預設帶字幕；已有的設定檔不改。

## 影片字幕

- 影片開啟 `2ae3`：DL 存入 `[065a]`。bit 2（值 4）時以 SQX 解壓器 `79fb` 解開字幕文字，條目指標＝偏移表第 BX 項－100h（`2b79`–`2b83`），存入 `[0644]`。
- 播放迴圈 `2bf0`：`[065a]` bit 2 且畫格 `[0674]` 達到 `[0648]` 時呼叫 `2c39`→`2c40`，複製一句到區塊 4434h，於 `2ce5` 呼叫 `86e9`。開場與說明影片共用這個呼叫點，接手後同樣以中文覆繪（docs/spec/004）。
- 切句（`2c57`–`2cba`）：略過開頭空白；逐字複製，遇 `. ; : ? !` 時看下一字，下一字也是這些字元、`^` 或 0 就繼續，否則結束；`^` 不複製；讀到 0 為最後一句。
- 文字檔：`TH{A,D,F,S}{1,2,3,4,H,I,T}.SQX`，A 為英文（D、F、S 推測為德、法、西文）。數字為章節的提示，H 為通用提示，I 為萬尼亞叔叔的開場獨白，T 為主角的開場獨白。有偏移表的檔：開頭為 16 位元小端偏移表（值減 100h 為位置），條目為 0 結尾字串；THAT、THAI 沒有偏移表，整檔一個條目。

# 006 開章程式、選章祕技與鍵盤中斷

第二到四章的譯文要在遊戲裡驗證，得先進得了那一章。本文記錄遊戲自己的開章路徑、原版的選章祕技，以及驗證時用的取證選項 `kgb-run --chapter N`。

## 1. 輸入

- `CSPPRG.EXE`（SHA-256 見 `workplace/disc/manifest.json`）。
- 第一章程式段傾印 `workplace/runs/seg188b-ch1.bin`（64 KiB，自 188B:0000 起，涵蓋資料段 2144h；SHA-256 `14d1ce6b04bf4e3a6694901fda991bc4c554fa4d0e8951ac1bf2873bde8891da`），反組譯 `workplace/runs/seg188b-ch1.asm`（objdump，16 位元）。
- 位址皆為 load segment 188Bh 內偏移，資料段 DS＝2144h。

## 2. 開章程式

| 位置 | 原始位元組與指令 | 角色 | 等級 |
|---|---|---|---|
| `1bb9`–`1bdf` | 進入後清 `cs:[1e89]`（`2e c6 06 89 1e 00`），`1bdf` `a2 0e 03` `mov [030e],al` | 開章：AL＝章號（1–4），AH＝FFh | 已證實（實機 ch2-d、ch3-a、ch4-a） |
| `18d6`–`18db` | `a0 0e 03` `mov al,[030e]`；`b4 ff`；`e8 db 02` `call 1bb9` | 新遊戲開章的呼叫點 | 已證實（trace-at，ch2-trace：唯一一次呼叫，AX＝FF01h） |
| `00cd`–`00d7`、`2703`–`2712` | 同樣以 AL 呼叫 `1bb9`；`2703` 由腳本變數 54h＋AH 取章號 | 主迴圈與讀檔的開章路徑 | 強推論（靜態），新遊戲流程未執行 |
| `[030e]` | 第一章傾印值 01h | 目前章節，1 起算 | 已證實 |
| `1e77`、`[0796]` | `1e77` 以 `([030e]−1)×2` 查表；`0796` 起 8 個指標指向 `CHAP1.PAC`–`CHAP4.PAC`、`MAP1.PAC`–`MAP4.PAC` 的「旗標＋檔名」 | 依章節取場景包 | 已證實（傾印與反組譯） |

## 3. 選章祕技

`6955` 由輸入輪詢 `6800` 結尾落入，`[4e4a]` 不為 0 才執行（第一章傾印值 FFh）。

- `6962`–`6995`：以 `[4e4b]`（`int 09h` 存的原始掃描碼）`and 7Fh` 依序比對 `[5125]` 起的序列 `2E 13 15 18 2E 23 2D 00`，即 C R Y O C H X；與前一鍵相同時略過，其他鍵重設。比對到結尾的 0 後，再按掃描碼 02h–05h（主鍵盤 1–4），以 `ax=1092h`、`dx=1..4` 呼叫 `4d08`，寫入腳本變數區（段 `[06de]`）的位元組變數 92h。已證實（cheat2f：`6981`、`698f` 各執行一次）。
- 寫入後的效果未證實：實測在說明影片中輸入，影片結束後進入片尾字幕（cheat2g、cheat1a）。沒有對照組，不能斷定片尾是祕技造成的，也不能斷定變數 92h 是章節。

## 4. 鍵盤中斷

遊戲在 `172b` 呼叫 `6508`，把 `int 09h` 掛到 `651d`。處理常式從埠 60h 讀掃描碼，寫入 `[4e4b]`（`6537` `a2 4b 4e`）與按鍵狀態表。FerroGolem 原本不送 IRQ1，`651d` 從不執行（cheat2e 的 trace-at 在 `6537` 為 0 次），祕技與按鍵狀態表都收不到輸入。FerroGolem `c827e1d` 補上 IRQ1（FerroGolem `docs/spec/003` §4）。

## 5. 取證選項 `kgb-run --chapter N`

第一次進入 `1bb9` 時把 AL 改成 N，其餘交給遊戲自己的開章程式；不寫入原版記憶體，只用於驗證，`kgb-play` 不帶這個選項。開場影片以虛擬時間播放，要在 1.0B 步左右進場景需搭配 `--cycles 1000`。

抽樣驗證（`--cycles 1000`，跑到 1.05B–1.2B 步）：

| 執行 | 章節標題 | 除時鐘外的文字事件 | 未譯 |
|---|---|---|---|
| ch2-d | Leningrad, Friday August 16, 1991. Hotel Gostinitsa... | 50 | 0 |
| ch3-a | Leningrad, Saturday August 17, 1991. The docks... | 51 | 0 |
| ch4-a | Leningrad, Sunday August 18, 1991. The docks... | 51 | 0 |

文字事件含開場字幕、章節標題、地點列與旁白，畫面上都以中文顯示，例如「205 號房」、「前往棧橋。」。各章的比對鍵分別取自 CHAP2A、CHAP3U、CHAP4U，命中代表遊戲實際用的是這幾組英文檔。

取證日期：2026-10-30。輸入：`INTRO.BGF`（SHA-256 `186e236c…6e4b707`）、`HELP.BGF`、`LOGOS.BGF`；`CSPPRG.EXE`（SHA-256 `d2fb547e…f5aac47c`）的程式段取自記憶體傾印（`workplace/runs/intro-dump1`，cycles 1000、46,100,000 步，load segment 188Bh，`objdump -m i8086`）。檔案結構以 `tools/bgf_walk.py`、`tools/bgf_frame.py`（Docker 內 `python3 -I`）讀取。

## BGF 結構

- 檔頭是 32 位元小端偏移表：第一項是表的長度（也是第 0 段起點），其餘為各段起點，最後一項等於檔案長度。INTRO 有 3 段（起點 10h、B8FE4Bh、DCA24Fh），LOGOS 3 段，HELP 156 段。INTRO、LOGOS 的最後一項等於檔長，已證實；HELP 未核對最後一項。
- 段內是連續畫格，每格開頭 16 位元小端長度（含自身）。沿長度走完，每段都剛好落在下一段起點。已證實。
- 帶聲音的畫格在長度後接 `73 64`（「sd」）、16 位元長度，第一格的內容以 Creative Voice File 檔頭開始，之後為 8 位元無號 PCM（中心 80h）。VOC 區塊 1 的時間常數 A6h，即 11,111 Hz。已證實（位元組）。

## 實跑對照（FerroGolem，cycles 1000）

- `INTRO.BGF` 以 handle 5 在 43,458,850 步開啟，46,148,353 步起 seek 到 14,459,471（第 2 段起點），直到 334M 步都在第 2 段內（`intro-seek1`、`intro-seek2`）。334,166,448 步開 `TCD2A.SCR`，336,715,325 步開 `THAI.SQX`，接著播第 0 段。
- 原版設定檔（字幕 00）與開字幕（FFh）時選段相同（`intro-seek3`），選段與字幕旗標無關。
- SB 的 8 位元 DMA 從約 337 秒開始，到約 485 秒，與第 0 段的語音一致（`audio-sbpro1`）。第 2 段本身沒有聲音資料，這段期間只有 AdLib 配樂（`KURSK.SQX`）與字幕。

## 結論

開場的主角獨白在原版就沒有數位語音，畫格裡也沒有聲音資料；萬尼亞叔叔的獨白帶語音，FerroGolem 已由 SB 播出。開場沒有缺聲音。先前把約 337–485 秒稱為「說明影片」，其實是開場第 0 段。

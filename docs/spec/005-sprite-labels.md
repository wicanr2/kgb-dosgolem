# 005 圖片文字覆繪（動作選單、物品選單、游標動詞、開場字卡）

狀態：READY。

## 1. 為什麼

動作選單、物品選單與游標旁的動詞（LOOK、TALK…）是 `SPRA.ANC` 的圖塊，不經文字 routine，接手（docs/spec/004）蓋不到。原版記憶體與畫面緩衝不寫入，所以在覆繪層把圖塊上的英文字蓋掉、畫上中文。

## 2. 證據

輸入：`CSPPRG.EXE`（SHA-256 見 `workplace/disc/manifest.json`）；第一章傾印（FerroGolem `workplace/runs/kgb-ch1dump`）；反組譯 `workplace/runs/seg188b-ch1.asm`（load segment 188Bh、資料段 2144h、驅動 51E0h）。

圖塊內容（`kgb-sprites` 以遊戲的 `85d5` 逐一畫出，`workplace/runs/spra-1`）：1–11 為游標動詞 LOOK、TALK、GO、USE、MOVE、FIGHT、LISTEN、KNOCK、HIDE、TAKE、DESTROY（高 7、深底亮字）；15 為物品選單（LOOK、USE、DESTROY、TAKE）；16 為動作選單（HIDE、TALK、GO、USE、MOVE、SMART POINTER、FIGHT、LISTEN、LOOK、KNOCK）。其餘圖塊沒有文字。

## 3. 契約

- 標籤表 `text/sprite-labels.tsv`：每列「圖塊編號、x、y、寬、高（圖塊內座標，蓋住英文字的矩形）、英文、繁中、簡中」。只列 SPRA 的圖塊。
- 選單（15、16）：執行到 `85f3` 且 DX＝`[2144:06d2]` 時，記下（編號 AX、x＝CX、y＝BX）。之後 40,000 步內圖塊畫進離屏緩衝，屆時從緩衝擷取各標籤矩形的像素（色號）當快照。同一圖塊的新事件取代舊的。
- 每次合成畫面：選單的各標籤矩形，目前畫面色號與快照相同的比例達 85% 才畫；低於就移除該選單（選單已關）。游標動詞：`[4f15]` 為 1–11（高位元組 0）才畫，位置為最近一次 `7093` 的 CX、BX。`7093` 之後 40,000 步從畫面（A0000）擷取標籤矩形的快照；有快照時，畫面該矩形與快照相同的比例達 85% 就一直畫，低於即移除（游標移走或換動詞）；還沒有快照時沿用「最近一次 `7093` 在 0.1 秒內」。滑鼠靜止時遊戲不再重畫游標，只看時間會在 0.1 秒後露出英文（gameplay-rec1 第 38 秒）。
- 畫法（3 倍覆繪層）：同一選單的底色與字色由全部標籤矩形的快照合起來決定，各按鈕一致。矩形以最常見的色號（底色）填滿，再以字色把譯文置中畫上。字色取數量達非底色最多者 10% 的色號中與底色亮度差最大者（原版字有多階陰影與大片暗邊，ex-card1：暗邊 1,004 點、各階亮字 120–192 點），字級取矩形高 × 3 × 0.85。游標動詞沒有快照，底色、字色以同一規則取自畫面該矩形。
- 不寫入原版記憶體；只讀暫存器與記憶體。所有位址先比對簽章：`85f3` 起 `1e 53 51 8e 06 c0 06 bf 00 64`，`7093` 起 `ff 1e ea 05`。

## 4. 驗收

- 單元測試：標籤表解析與欄數檢查；快照比對（相同、部分不同、完全不同）；底色與字色的選取。
- 實機：右鍵開動作選單，各按鈕顯示中文；選單關閉後中文消失；滑鼠移到物件上，游標動詞顯示中文（例：畫像為「檢視」）。

## 5. 開場字卡

證據（`workplace/runs/ex-card1`、`ex-card2`、`ex-card3`，cycles 1000）：`TCD1A.SCR`（「Moscow, August 1991...」）在 #43,458,945 開檔，`51e0:0c05` 於 #43,477,631 起整格搬上畫面，#46,264,113 起開場影片（`188b:3350` 起的展開迴圈）覆寫畫面。`TCD2A.SCR`（「Some days before...」）在 #334,166,448 開檔，同樣整張顯示。字卡文字列在第 86–106 列附近，背景色號 0。檔名第 5 字母 A 為英文版，D、F、S 另有版本。

契約：

- 字卡標籤表 `text/card-labels.tsv`：每列「檔名、x、y、寬、高、英文、繁中、簡中」。
- 開檔（DOS 3Dh）檔名與表上相符時記下步數。之後第一波寫到矩形的畫面寫入算上屏，相鄰寫入相差超過 100,000 步的新一波寫到矩形就移除（與 docs/spec/004 §5 相同規則）。
- 畫法：每次合成時以 §3 的規則從畫面矩形取底色與字色，所以調色盤淡入淡出時中文跟著變亮變暗。

# 004 KGB 文字 routine 接手

狀態：READY（§2、§3、§5、§7、§8）。§5 只涵蓋 mode 13h 鏈結畫面。

## 1. 為什麼

使用者定案（2026-10-29）：接手文字 routine、跳過原版英文繪字、中文畫在 3 倍覆繪層。原版字幕行高 9–12 像素，原生解析度放不下可讀的中文。

## 2. 證據

輸入：`CSPPRG.EXE` SHA-256 見 `workplace/disc/manifest.json`；記憶體傾印 `workplace/runs/rs-r15/out/ram.bin`（自有核心 50,000,000 步）。解壓後的程式碼在 load segment（PSP＋10h，本次 188Bh）。反組譯工具 `objdump -m i8086`（binutils，`dosgolem-rust-sc:1.99.1-r1`），位址為 load segment 內偏移。推論等級在每列註明；IDA 交叉驗證列在 worklist `ida-text-routines`。

| 偏移 | 簽章（16 bytes） | 角色 | 等級 |
|---|---|---|---|
| `86e9` | `50 52 56 55 06 53 51 8d 31 8b 4d 02 2b cb bb 00` | 文字區塊（一頁）：DI＝區塊（+2 結尾索引、+4 寬度，資料自 +8 起），BX＝起始索引，CX＝x，DX＝y，BP＝最多行數。從 BX 數行：0 是行界，遇到第一個 `^` 即停（`^` 是換頁）；行數取與 BP 較小者，y 加（BP－行數）×6。逐行量寬置中後呼叫 `87d8`，行距 `[7691]`。返回時 AX、DX、SI、BP、ES 還原；**BX＝最後一行結尾字元之後的索引**（沒有行時為輸入值）；CX 等於輸入值。精確演算法見 §3 | 強推論 |
| `87d8` | `fc 55 56 06 8a 36 0e 44 8b f7 8b f9 8b cb ac 3c` | 單行：DS:DI＝字串，CX＝x，BX＝y，顏色 `[440e]`。逐字以 `87c2` 取寬、經 `lcall es:[054a]`（ES＝2144h）畫字形。結束時 DI＝結尾字元之後、CX＝輸入 BX、DH＝`[440e]`、AL＝結尾字元（0 或 `^`） | 強推論 |
| `2c40`–`2cf0` | `bf 34 44 c7 45 02 08 00 c7 45 06 00 00 b8 40 01` | 開場字幕：從全文 `[0644]` 複製一句到區塊 4434h（遇 `. ; : ? !`、`^`、0 結束），顯示時間＝字數×`[0654]`÷16，於 `2ce5` 呼叫 `86e9`（CX＝0、DX＝B5h、BP＝2） | 強推論 |

- `86e9` 的呼叫點：`2ce5`、`529d`、`584c`、`7727`。
- `87d8` 的直接呼叫點：`1d94`、`2a82`、`3e10`、`69c9`、`86b0`，以及 `86e9` 內的 `875f`。
- 字形像素（驅動 `51e0:12d1`，由 `lcall es:[054a]` 經 `51e0:0124` 轉入）：每個像素一個位元組，0 為透明；低半位元組非 0 時寫 `DH＋(值 & 0Fh)`，DH＝`[440e]`；低半位元組為 0 時寫 0（黑色陰影）。開場字幕 `[440e]`＝254，傾印中字幕像素為 255（590 個），一行頂端 y＝187＝181＋(2−1)×6。已證實（程式碼與傾印一致）。
- 字型狀態：`[768f]` 字型段、`[7691]` 行高（9、10、12）、`[7693]` 字距，由 `8774`、`8789`、`879e`、`87b3` 切換。

## 3. 攔截契約

- 只接手 `TAKEN_SITES` 列出的呼叫點（返回偏移）：`2ce8` 開場字幕、`1d97` 章節標題列、`52a0` 地點標籤、`584f` 旁白（kgb-r9、kgb-r10 取證）、`3e13` 對話選單（ex-belov1）。其他呼叫點只記錄事件、CPU 不變、原版照畫；例如 `86b3` 時鐘用特殊數字字型，不接手。
- 每步執行前，若 CS＝load segment 且 IP 為 `86e9` 或 `87d8`，先比對該處 16 bytes 簽章，不符就不攔截並記錄一次「簽章不符」。
- `86e9`：讀 DS:DI 區塊的 `[BX, [DI+2])` 位元組為原文，連同 CX、DX、BP、`[7691]`、`[440e]`、`[768f]`、呼叫點（堆疊頂的返回偏移）記成文字事件。依原版演算法算出返回的 BX，寫回 BX，再模擬近返回（彈出 IP）。呼叫端以返回的 BX 判斷顯示了多少、還有沒有下一頁（`584f` 起：`pop ax; sub ax,bx; neg ax`），所以 BX 必須與原版一致。
- 返回 BX 的演算法（`86f0`–`876c`，令 b(i)＝區塊位元組，e＝`[DI+2]`）：
  1. 數行：e ≤ BX 時行數 n＝0。否則從 i＝BX 起逐字讀 c＝b(i)：c＝`^` 時 n＋1 並停止；c＝0 時 n＋1；讀到 e 為止。停止於 e 而最後一字非 0 時 n＋1。之後若「最後讀到的字 OR 它前一字」為 0，n－1。
  2. n＝min(n, BP)（無號比較）。
  3. 畫 n 行：每行從目前索引讀到 `^` 或 0（索引越過該字）或索引達 e。n 行之後的索引就是返回的 BX；n＝0 時返回輸入的 BX。
- 依據：上列反組譯（`workplace/runs/rs-r15/out/seg188b.asm`）。舊版本契約不設 BX，旁白（`584f`）每次點擊都從頭重顯第一頁，無法進入互動（`ex-office3`）。
- `87d8`：返回偏移為 `8762`（`86e9` 內部）時不會發生，因為外層已被攔截。其他呼叫點：讀 DS:DI 起到 0 或 `^` 的原文記成事件，設定 DI、CX、DH、AL 如 §2 表，ZF＝1，再模擬近返回。
- 對話選單 `3e13`（`3dd6`–`3e10`）：選單區塊以 `^` 分行，逐行以 `87c2` 量寬，x＝`[029e]`＋0Fh＋（`[4a1c]`－英文寬）÷2 置中後呼叫 `87d8`。行尾的 `7Fh` 是遊戲字型的右箭頭（子選單）。單行事件因此另記英文寬（同 `87c2`：字形寬位元組＋`[7693]` 字距，取低位元組）與是否置中；覆繪把中文置中在英文行的中點。查譯文時先去掉行尾的 `7Fh` 與空白，譯文後補「 ▶」。
- 不寫入原版記憶體；只改 CPU 暫存器與 SP。

## 4. 文字事件

`{步數, 種類(block/line), 呼叫點, 原文 bytes, x, y, 最多行數, 行高, 顏色索引, 字型段}`。原文是比對鍵，譯文表 `text/*.zh-TW.tsv` 以原文查找。

換頁：`^` 分頁，原版一次只畫一頁，下一頁由呼叫端以返回的 BX 再呼叫一次。事件另記整塊原文 `[8, e)`（區塊資料起點固定為 +8：`2c40`、`7650`、`72cd` 都把 `[DI+2]` 設為 8）與頁序（`[8, BX)` 內 `^` 的個數）。覆繪文字的選法：

1. 以本次原文 `[BX, e)` 查到譯文：顯示譯文的第 0 頁（以 `^` 切頁）。
2. 查不到且頁序大於 0：以整塊原文查，顯示譯文的第「頁序」頁。
3. 都查不到：以英文畫本頁，就是原版這次會畫的 `[BX, 返回 BX)`。

譯文的 `^` 個數必須與原文相同（`tools/merge_translations.py` 檢查），頁才對得上。若原版因 BP 不足而在頁中斷開，下一次呼叫的頁序不變，覆繪重顯同一頁譯文。區塊原文去掉結尾的 0 與空白，中間的 0 還原成空白：`188b:5bed` 附加字元時依字寬自動換行，把行尾空白改成 0（整行沒有空白時才硬插 0），`^` 才是原文自帶的換行。比對鍵因此與區塊寬度無關，也與片語萃取（docs/re/004）的文字一致。

## 5. 覆繪生命週期

證據（FerroGolem 探針、原版照畫、監看 A0000 第 181–199 列的寫入；FerroGolem `workplace/runs/kgb-w1`、`kgb-w2`）：

- `51e0:0bcd` 每句把整條字幕帶（19 列 × 320）搬到螢幕一次：80M 步內 6 次、334M 步內 31 次，與第一段 31 句一一對應。最後一次在 #303,720,929，最後一句事件在 #302,922,874。
- 最後一句之後沒有清除字幕帶的搬移；字幕留到換場時 `51e0:0c05` 的整格重繪（#330,140,227 前後）才被蓋掉。

契約（`crates/kgb-cht/src/lifecycle.rs`）：

- 新事件取代同一呼叫點、同一種類的項目；單行事件另要同一 y 才取代（對話選單在同一呼叫點逐行畫出，ex-belov5）。
- 事件後第一波寫到項目範圍的螢幕寫入算上屏；相鄰寫入相差超過 100,000 步視為新的一波，新的一波寫到範圍就移除項目。
- 範圍：區塊為 `[x, x+寬) × [y, y+最多行數×行高+1)`，單行為 `[x, 320) × [y, y+行高)`，以 320×200 畫面計。
- 驗收：`kgb-r8` 跑 334M 步，31 句全部顯示譯文，換場時移除 1 次；畫面確認最後一句在換場前仍在、換場後消失。
- 非 mode 13h 鏈結的畫面尚未量測，遇到時另立規格。

## 6. 驗收

- `crates/kgb-cht/tests/takeover.rs`：以最小 MZ 在真實偏移放簽章、從 `2ce5`、`1d94` 呼叫；`86e9` 跳過後 BX 依 §3 演算法前進，其餘暫存器除 IP、SP 外不變；返回 BX 的演算法另有單元測試（多頁、行數超過 BP、空區塊）；`87d8` 輸出 DI、CX、DH、AL 符合 §2；簽章不符不攔截（負對照）；白名單外只記錄、CPU 不變。
- 英文退路（沒有譯文時）在覆繪層畫原版這一頁會畫的文字 `[BX, 返回 BX)`。
- 第一章旁白：點擊後顯示第二頁，再點擊後進入互動（游標移到場景物件時地點列改變）。
- KGB 開場：事件序列的原文與 `2CF32h` 全文的句子順序一致；畫面上沒有英文字形。

## 7. 多片語區塊

證據（`ex-office4`，`kgb-run --trace-phrases`，cycles 1000）：

- 地點列 `52a0` 的「Inspect yourself.」由兩次 `53d8` 組成：返回 `53b7`、片語偏移 `cb9b`、起點索引 8，以及返回 `5709`、`c9ff`、起點 16，都寫入區塊 `4a18`。
- 旁白 `584f` 的「Maksim Mikhailovich Rukov, dashing KGB daredevil. You're wearing a KGB captain's uniform.」由五次 `53d8`（返回 `52ec`）寫入區塊 `4434`，起點 8、58、73、75、97。
- `764a`（框內訊息，`7727` 畫出）在 `7650` 把 `4a18` 重設為 8，再依序解碼最多 4 個片語。

`53d8` 從區塊目前的結尾索引 `[ES:DI+2]` 接著寫（docs/re/004），所以一次呼叫的起點就是該片語在區塊中的起點。片語之外的字（`5bed` 附加的 `-`、`:`，`5718` 附加的名稱）落在片語之間。

契約：

- 每次執行到 `53d8`，以（ES, DI）為區塊鍵記下起點 `[ES:DI+2]`。起點不大於該區塊上一筆時，視為區塊重建，清掉舊的起點。只記錄，不改狀態。
- 區塊事件依 §4 的順序查不到譯文，且該區塊有起點紀錄時，組合譯文：把整塊 `[8, e)` 依起點切段；片語段以該段原文（正規化同 §4）查譯文表，查不到用英文；片語之外的段保留原文。各段相接，兩側都是中文時不加空白。組成的譯文以 `^` 分頁，顯示第「頁序」頁。
- 組合結果只影響覆繪，不寫入原版記憶體。所有片語段都查到譯文時，計為已譯。

狀態：READY（證據為上列追蹤；中文語序以片語為單位相接，品質由 worklist `chapter1-review` 校對）。

## 8. 插槽範本

證據（反組譯 `seg188b.asm`；萃取 `workplace/runs/extract-2`）：

- 片語解碼器 `53d8` 讀到 1FFAh 以上的字碼時，在 `5443` 呼叫 `56d5`，AL＝字碼低位元組。`56d5`：AL＜FCh 時以 `[031c]` 經 `5718` 附加名稱（字詞表，逐字至高位元結束，後補空白，撇號除外），再以 `[031a]` 的片語偏移在 `5706` 遞迴呼叫 `53d8`；AL≥FCh 且 `[0319]` 非 0 時改用 `[0318]`、`[0316]`；都沒有時經 `lcall [050e]`（DX＝`[0420]`）設定預設代名詞並回 CF＝1，由 `5469` 起把代名詞當一般字寫入。強推論。
- 第一章 40 個片語含插槽，字碼只有 FAh、FCh、FEh。萃取時沒有物件，FAh 插槽為空、FCh 與 FEh 插槽為空且後接代名詞「him」。
- 實機（`ex-office4`）：地點列「Inspect yourself.」是片語 3380「Inspect him.」在 FEh 插槽遞迴解碼片語 3339「yourself」，其後的「.」仍屬外層片語。

範本與鍵：

- 插槽內容中由 `5718` 附加的冠詞 the、a、an 中文略去。
- 範本是把插槽內容換成 `{字碼}` 的原文；空插槽之後緊接的代名詞 him、her、it（後面不是字母）併入插槽，不留在範本裡。例：`Inspect {fe}.`、`Put {fa} in {fe}.`。
- 範本譯文表 `text/chapter1-templates.zh-TW.tsv`，key 為範本的 FNV-1a 64 雜湊，譯文以相同的 `{字碼}` 標出插槽，每個標記恰好出現一次（`tools/make_templates.py` 檢查）。
- 執行期以返回位址與 SP 追蹤 `53d8` 與 `56d5` 的進出，記下每段的範圍、深度與字碼。區塊事件依 §4、§7 查不到整句時：最外層片語段若含插槽，以同樣規則組出範本鍵查範本譯文；插槽內容（名稱、遞迴片語或併入的代名詞）各自查譯文（代名詞 him、her、it 對應「他」「她」「它」），填入標記。範本查不到時退回 §7 的逐段組合。

# 002 EMS（int 67h）

狀態：CONFORMED（單元測試與 KGB 啟動路徑）。

## 依據

移植 Go dosgolem `f79eab6` 的 `internal/dos/ems.go`，契約為該庫 `docs/spec/008-ems-paging`、`014-ems`、`429-ems-move-exchange-region`。

## 契約

- 偵測：`int 67h` 向量指向 `0050:0000`，該處 `CD F6 CF`，`+0Ah` 為 `EMMXXXX0`。`int F6h` 分派到 EMS。
- page frame 在 D000h 段，四個 16 KB 實體頁；總頁數 512。複製式分頁：換映射、釋放、4Eh 取回、48h 還原前先寫回。
- 支援 40h–46h、47h／48h、4Bh、4Ch、4Eh（00–03）、50h（00、01，先檢查再套用）、51h、57h（00、01）、58h。其他回 84h 並記在 `Ems::unsupported`。
- 回傳慣例：AH＝0 成功，非 0 為錯誤碼，不動 CF。0 頁配置回 87h，沿 Go 既有行為（LIM 手冊寫 89h，Go 標為假說）。

## 驗收

- `ems.rs` 單元測試：簽章與向量、頁數與錯誤碼、換頁寫回（含負對照）、50h 原子性、57h 搬到未映射頁。
- KGB：`int 67h` 41h、42h、43h（32 頁，handle 1）通過，啟動繼續（`workplace/runs/rs-r2`）。
